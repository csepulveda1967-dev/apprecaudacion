# Sistema Integral de Control de Inventarios para Bar y Cocina

Sistema de gestión operativa y gerencial para establecimientos gastronómicos, diseñado para optimizar el control de existencias, rotación FIFO, mermas, pedidos por stock mínimo y auditoría en tiempo real.

## Aplicaciones Principales

1. **app_operacion_bar.html**: Aplicación web interactiva para el equipo de barra (bartender / encargado de turno). Incluye control de apertura y cierre diario por fecha, solicitudes sugeridas por stock mínimo, solicitudes libres para eventos especiales, recepción física ajustable y maestro de stock en vivo.
2. **app_panel_gerencial.html**: Panel de administración y supervisión ejecutiva. Muestra indicadores clave (KPIs de valorización en dinero, alertas y pendientes), bitácora inalterable de auditoría en tiempo real y exportación directa a Microsoft Excel (.xlsx).

## Documentación y Planillas de Soporte

- **sistema_inventario_bar_cocina_integrado.xlsx**: Planilla de cálculo estructurada con áreas separadas de Bar y Cocina (por cuartos operativos), alertas automáticas de reposición y maestro de movimientos.
- **manual_funcional_sistema_inventario_cocina_bar.docx**: Manual operativo y de procedimientos gastronómicos.
- **diseno_tecnico_sistema_inventario_cocina_bar.md**: Especificación técnica de arquitectura, entidades de datos y reglas de negocio.
